# images/

This folder is reserved for local image assets (logo, screenshots, event photos, etc.)
if you want to replace the placeholder Unsplash images used in the HTML files.

Currently, all images in this project are loaded from public Unsplash URLs so the
site works immediately without needing any local files. To use your own images:

1. Save your image files here, e.g. `images/hero.jpg`, `images/event1.jpg`.
2. In the HTML files, update the relevant `<img src="...">` attribute to point to
   the local path, e.g. `src="images/hero.jpg"`.

No image files are required for the project to run.
